THE MISSING LAYER

A snapshot tells an agent what exists.
History should tell it why.

DURABLE WORK

The model owns the next decision.
Git owns the process.

An invocation can stop when it reaches CI, a human review or any external event. Its continuation lives in a Git ref, not in a context window.

01startclaim lease
02changebounded scope
03awaitpersist continuation
invocation exits no polling · no chat state
04resumefresh agent
05finishrecord decision
shell
$ usegit start --goal "reduce reality gap" --hypothesis "contact shadows help"
→ WORK-1234ABCD · lease: chatgpt-a · active

$ usegit await WORK-1234ABCD --event ci:gpu-render \
    --on-success "combine with material experiment"
→ awaiting · lease released · continuation persisted

# another invocation, another agent, no previous chat required
$ usegit context
→ awaiting: WORK-1234ABCD · event: ci:gpu-render

$ usegit resume WORK-1234ABCD --result success --evidence "gap 0.091 → 0.074"
